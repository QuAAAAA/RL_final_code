% ----------------------------------
% Abstract
% ----------------------------------
  \begin{block}{Abstract}
    We address emotional capability loss when an expressive text-to-speech
    (TTS) model trained on a high-resource language is adapted to a
    low-resource language. Using IndexTTS2 as the expressive base model, we
    propose an RL-enhanced adaptation framework for preserving emotional
    controllability, prosodic richness, and speech naturalness during transfer
    from Chinese to Taiwanese. The goal is to retain the pretrained emotional
    prior and realign it to limited target-language data.
  \end{block}

% ----------------------------------
% Motivation and objectives
% ----------------------------------
  \begin{alertblock}{Motivation and Objectives}
    Expressive low-resource TTS is limited by a tension between pronunciation
    adaptation and emotion preservation. Naive fine-tuning can improve
    intelligibility while flattening rhythm, pauses, emphasis, and intensity.

    \begin{itemize}
      \item \textbf{Emotional forgetting:} target-language fine-tuning can erase
      expressive behavior learned from high-resource speech.
      \item \textbf{Prosodic control loss:} adapted speech may stay intelligible
      but lose natural emphasis and intensity control.
      \item \textbf{Cross-lingual alignment:} emotional cues do not transfer
      perfectly across languages with different phonology and rhythm.
      \item \textbf{Objective:} recover controllable emotional expression in
      Taiwanese TTS through RL-based realignment.
    \end{itemize}
  \end{alertblock}

% ----------------------------------
% Method overview
% ----------------------------------
  \begin{block}{Proposed Framework}
    The method first adapts the expressive base model to Taiwanese
    pronunciation, then applies RL to recover controllable emotion and prosody.

    \input{images/figure1}

    \begin{itemize}
      \item \textbf{Stage 1:} LoRA or adapter-based adaptation limits parameter
      drift and reduces catastrophic forgetting.
      \item \textbf{Stage 2:} GRPO optimizes the autoregressive
      text-to-semantic policy with waveform-level rewards.
      \item \textbf{Anchor:} a KL penalty preserves pronunciation, timbre, and
      the adapted reference behavior.
    \end{itemize}
  \end{block}

% ----------------------------------
% Formulation
% ----------------------------------
  \begin{block}{RL Formulation}
    Semantic speech generation is formulated as an MDP over the IndexTTS2
    text-to-semantic module.

    \begin{itemize}
      \item \textbf{State:} input text, speaker timbre, duration constraint,
      target emotion, and prior semantic tokens.
      \item \textbf{Action:} the next discrete semantic speech token from
      policy $\pi_\theta$.
      \item \textbf{Reward:} a sequence-level score computed from the decoded
      waveform.
    \end{itemize}

    \[
      R = \lambda_1 R_{\mathrm{emo}}
        + \lambda_2 R_{\mathrm{intensity}}
        + \lambda_3 R_{\mathrm{emphasis}}
        + \lambda_4 R_{\mathrm{ASR}}
    \]

    \[
      \max_\theta\; \mathbb{E}[R(s,a)]
      - \beta\,\operatorname{KL}\!\left(\pi_\theta(\cdot|s)\,\|\,p_{\mathrm{adapt}}(\cdot|s)\right)
    \]
  \end{block}

% ----------------------------------
% Datasets and baselines
% ----------------------------------
  \begin{block}{Datasets and Baselines}
    The experiment is designed to separate basic language adaptation from
    emotional recovery, so each model is evaluated before adaptation, after
    low-resource adaptation, and after RL realignment.

    \begin{itemize}
      \item \textbf{Emotion supervision:} ESD and Expresso provide emotion
      labels, intensity cues, and emphasis annotations.
      \item \textbf{Taiwanese adaptation:} TAT\_MOE supports target-language
      adaptation and evaluation with low-resource subsets of roughly 1--5 hours.
      \item \textbf{Baselines:} high-resource IndexTTS2, naive fine-tuning,
      parameter-efficient adaptation, our RL-enhanced model, and CosyVoice3.
      \item \textbf{Core comparison:} Emotion Retention Gap and recovery ratio
      measure how much expressiveness is lost and then restored.
    \end{itemize}
  \end{block}

% -------------------------------
% Architecture and reward design
% -------------------------------
  \begin{block}{Architecture and Reward Design}
    \input{images/figure2}

    Reward models evaluate decoded speech rather than only token likelihood.

    \begin{itemize}
      \item \textbf{Emotion category:} emotion2vec checks target emotion match.
      \item \textbf{Global intensity:} VAD distance from a neutral centroid
      encourages stronger affect.
      \item \textbf{Local emphasis:} pitch and energy patterns measure stressed
      words and expressive prosody.
      \item \textbf{Content accuracy:} ASR transcription compares generated
      speech with the input text.
    \end{itemize}
  \end{block}

% -------------------------------
% Evaluation
% -------------------------------
  \begin{block}{Evaluation Protocol}
    We evaluate intelligibility, speaker fidelity, emotional expressiveness,
    and prosodic control across three stages: source model, adapted model, and
    RL-optimized model.

    \begin{itemize}
      \item \textbf{Objective metrics:} WER from ASR, speaker similarity,
      emotion similarity or accuracy, Emotion Retention Gap, and recovery ratio.
      \item \textbf{Subjective MOS:} QMOS, SMOS, PMOS, and EMOS on a 1--5 scale
      for quality, speaker identity, prosody, and emotion match.
      \item \textbf{Fine-grained tests:} Emotion Intensity Test compares weak,
      medium, and strong generations; Emphasis Accuracy Test checks perceived
      stress locations.
      \item \textbf{Trade-off check:} gains in emotion should not degrade WER,
      speaker similarity, or naturalness.
    \end{itemize}
  \end{block}
