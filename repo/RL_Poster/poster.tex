% ----------------------------------
% Abstract
% ----------------------------------
  \begin{block}{Abstract}
    We study emotional capability loss when an expressive TTS model trained on
    high-resource languages is adapted to Taiwanese. Building on IndexTTS2, the
    final system combines parameter-efficient adaptation, RL-based emotional
    realignment, and \emph{VA-and-stress control}. The goal is to preserve the
    pretrained expressive prior while improving emotion intensity, lexical
    emphasis, and speech naturalness in Taiwanese.
  \end{block}

% ----------------------------------
% Motivation and objectives
% ----------------------------------
  \begin{alertblock}{Problem and Objectives}
    Low-resource adaptation often improves pronunciation but weakens the
    expressive behavior learned from high-resource speech. The final report
    frames this as an emotion preservation and alignment problem.

    \begin{itemize}
      \item \textbf{Emotional forgetting:} limited Taiwanese fine-tuning can make
      synthesized speech flatter and less controllable.
      \item \textbf{Prosodic control loss:} rhythm, pauses, local stress, and
      emotional intensity may degrade even when speech remains intelligible.
      \item \textbf{Cross-lingual alignment:} emotion cues do not transfer
      perfectly across Chinese, English, and Taiwanese phonology.
      \item \textbf{Objective:} recover controllable emotional expression through
      RL-based realignment and VA-conditioned lexical stress control.
    \end{itemize}
  \end{alertblock}

% ----------------------------------
% Method overview
% ----------------------------------
  \begin{block}{Proposed Framework}
    The final method follows a two-stage IndexTTS2 pipeline with an annotation
    and phonemic text front-end placed between adaptation and evaluation.

    \input{images/figure1}

    \begin{itemize}
      \item \textbf{Stage 1:} LoRA or lightweight adapters learn Taiwanese
      pronunciation while limiting catastrophic parameter drift.
      \item \textbf{ASQP control:} Traditional Chinese aspect--sentiment
      annotations provide Valence--Arousal signals and sentiment-bearing spans.
      \item \textbf{Phonemic front-end:} Taiwanese text is rendered as
      T\^ai-l\^o romanization with tone digits, while emphasis markers are kept
      visible to the policy.
      \item \textbf{Stage 2:} GRPO updates the autoregressive text-to-semantic
      policy using waveform-level rewards.
    \end{itemize}
  \end{block}

% ----------------------------------
% Formulation
% ----------------------------------
  \begin{block}{RL Formulation}
    Semantic speech generation is formulated as a fully observable MDP over the
    IndexTTS2 autoregressive decoder.

    \begin{itemize}
      \item \textbf{State:} decoder hidden state conditioned on input text,
      speaker embedding, duration, target emotion, and prior speech tokens.
      \item \textbf{Action:} the next discrete semantic speech token from
      policy $\pi_\theta(A_t|S_t)$.
      \item \textbf{Reward:} a sequence-level score computed after decoding the
      semantic tokens into a waveform.
    \end{itemize}

    \[
      R = \lambda_1 R_{\mathrm{emo\text{-}cls}}
        + \lambda_2 R_{\mathrm{intensity}}
        + \lambda_3 R_{\mathrm{emphasis}}
        + \lambda_4 R_{\mathrm{ASR}}
    \]

    \[
      \max_\theta\; \mathbb{E}_{s,a\sim\pi_\theta}\!\left[R(s,a)\right]
      - \beta\,\operatorname{KL}\!\left(\pi_\theta(\cdot|s)\,\|\,p_{\mathrm{adapt}}(\cdot|s)\right)
    \]
  \end{block}

% ----------------------------------
% Data and synthesis
% ----------------------------------
  \begin{block}{Data and Synthesis Setup}
    \begin{itemize}
      \item \textbf{Training corpus:} TAT-MOE provides roughly 200 hours of
      native Taiwanese speech for low-resource adaptation.
      \item \textbf{Evaluation corpus:} TAT-Vol1 validation and test sets provide
      about 5 hours each; the synthesis study uses 2,752 utterances.
      \item \textbf{Emotion set:} each utterance is rendered with one of seven
      target categories: angry, happy, fearful, disgusted, sad, surprised, and
      neutral.
      \item \textbf{Controlled speaker:} all systems share one fixed Taiwanese
      reference speaker, producing 27:04:06 total synthesized audio with 44
      failed generations across CosyVoice baselines.
    \end{itemize}
  \end{block}

% ----------------------------------
% Evaluation metrics
% ----------------------------------
  \begin{block}{Evaluation Metrics}
    \begin{itemize}
      \item \textbf{SER:} emotion2vec recognition accuracy by target emotion and
      corpus-wide mean.
      \item \textbf{WER:} Taiwanese pinyin ASR evaluates intelligibility; the
      IndexTTS2 rows use the same tone-insensitive scoring pipeline.
      \item \textbf{SS:} ECAPA-TDNN speaker embeddings measure timbre retention
      against the fixed Taiwanese reference speaker.
      \item \textbf{MOS pilot:} 12 SARC members produced 600 ratings; CosyVoice2
      reached 4.31 mean MOS, shifting the focus from quality to emotion recovery.
    \end{itemize}
  \end{block}

% -------------------------------
% Architecture and reward design
% -------------------------------
  \begin{block}{Architecture and Reward Design}
    \input{images/figure2}

    Reward models evaluate decoded speech rather than only token likelihood.

    \begin{itemize}
      \item \textbf{Emotion category:} emotion2vec checks whether the waveform
      matches the requested emotion label.
      \item \textbf{Global intensity:} distance from a neutral centroid in
      Valence--Arousal--Dominance space encourages stronger affect.
      \item \textbf{Local emphasis:} pitch and energy patterns reward stressed
      words marked by the ASQP-derived control signal.
      \item \textbf{Content accuracy:} a Taiwanese pinyin ASR model evaluates
      whether emotional rendering preserves the input sentence.
    \end{itemize}
  \end{block}

% -------------------------------
% Results
% -------------------------------
  \begin{block}{Final Report Results}
    The final report evaluates emotion recognizability, intelligibility, and
    speaker fidelity across CosyVoice baselines and IndexTTS2 ablations.

    \input{tables/table1}

    \begin{itemize}
      \item \textbf{Emotion recognition:} all IndexTTS2 variants outperform
      CosyVoice2/3 in mean SER accuracy; the full proposed system is highest
      at 0.30.
      \item \textbf{VA-and-stress after RL:} control has little effect before RL
      (0.27 $\rightarrow$ 0.27 SER), but improves the RL checkpoint
      (0.28 $\rightarrow$ 0.30), driven by happy emotion accuracy
      (0.41 $\rightarrow$ 0.58).
      \item \textbf{Intelligibility trade-off:} WER rises from 0.705 to 0.840
      from plain fine-tuning to the full system, a bounded cost for stronger
      emotional rendering.
      \item \textbf{Speaker fidelity:} stronger emotion control lowers speaker
      similarity, especially after RL, making timbre preservation the main next
      challenge.
    \end{itemize}
  \end{block}

% -------------------------------
% Diagnostic findings
% -------------------------------
  \begin{exampleblock}{Key Findings and Next Step}
    \begin{itemize}
      \item IndexTTS2 moves to the opposite side of the baseline trade-off:
      better emotion recognition than CosyVoice2/3, but weaker speaker
      similarity.
      \item RL realignment reshapes the emotional profile, improving surprise
      and making VA-and-stress control more effective.
      \item Sad, fear, and disgust remain difficult under the current SER-based
      evaluation, suggesting that reward models and data balance need further
      refinement.
      \item Next stage: improve speaker similarity while retaining the emotion
      gains from RL realignment and VA-and-stress control.
    \end{itemize}
  \end{exampleblock}
